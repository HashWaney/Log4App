# Noto Sans SC

`NotoSansSC-VF.ttf` is the variable Noto Sans SC font from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/notosanssc).
The upstream file is named `NotoSansSC[wght].ttf`; it is renamed here only to
keep the asset path simple. The font is distributed under the SIL Open Font
License 1.1 in `OFL.txt`.

Source: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
